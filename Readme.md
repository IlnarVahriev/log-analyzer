# Анализатор журналов событий

Это консольная программа на Node.js, которая читает большие файлы логов, фильтрует их по разным параметрам и выдает статистику. Программа читает файл по кусочкам (потоково), поэтому не загружает его целиком в оперативную память.

## Бизнес-требования
Службе поддержки нужно быстро находить ошибки в логах разных сервисов. Программа должна:
- принимать путь к файлу и параметры через командную строку;
- фильтровать записи по времени (от и до), уровню важности (level) и источнику (source);
- считать, сколько всего строк, сколько из них корректных, а сколько битых;
- показывать номера ошибочных строк;
- считать статистику по уровням, источникам и топ самых частых кодов ошибок;
- сохранять результат в файл в формате JSON или CSV.

## Реализованный функционал
- Потоковое чтение файла (модули `fs` и `readline`).
- Валидация (проверка) каждой строки. Проверяется формат даты (ISO 8601), допустимые уровни (TRACE, DEBUG, INFO, WARN, ERROR), наличие всех 5 полей и отсутствие лишних символов `|`.
- Фильтрация. Время "от" включается в поиск, время "до" — не включается. Фильтры по уровню и источнику работают точно по совпадению.
- Сбор статистики. Подсчет ведется с помощью коллекции `Map`.
- Вывод в терминал в виде читаемого текста.
- Сохранение в файл JSON или CSV.
- Обработка ошибок (если файл не передан, не найден или пустой).

## Эндпоинты
Нет. Это консольное приложение (CLI), у него нет HTTP-эндпоинтов.
